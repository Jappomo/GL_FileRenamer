# File Batch Renamer (v1.1)

A simple GUI tool (built with Python + Tkinter) to batch rename files.  
Supports **search & replace**, **add prefix**, and **add suffix** operations.


## Download

You can download the pre-built version from the Releases section, or build it yourself from the source.
